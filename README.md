# gospherex-ig

Public image hosting for the Instagram account of GoSphere Environmental Action ry (@gospherex.earth), served with GitHub Pages.

The Instagram API downloads each post or story image from a public HTTPS address. Images live in `ig/` and are served at:

`https://gospherex.github.io/gospherex-ig/ig/<file>.jpg`

Rules:

- Only material already approved for publication goes here, on the day it is published.
- No personal data, no unpublished photos of people, no documents.
- File names: `AAAA-MM-DD-<tipo>-<tema>.jpg` (JPEG, stories 1080x1920, posts 1080x1350).

Website: https://gospherex.com
